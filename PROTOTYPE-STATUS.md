# Initial source snapshot

This is the reviewed simulated-transport software prototype published on 2026-11-09. It preserves one MinimalJoystick controller identity across simulated USB/Bluetooth input sources. It is not a signed public product release. Newer physical USB bridge development is not included in this initial snapshot.

Original software is MIT licensed. Microsoft-derived driver files retain MS-PL and the pinned upstream provenance. Source checks pass locally; hosted CI, native-driver reproducibility, public signing and flight-simulator acceptance require separate evidence.
