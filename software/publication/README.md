# MinimalJoystick publication status

Public repository: https://github.com/MinimalJoystick/MinimalJoystick. Original software is MIT licensed; the Microsoft-derived driver retains MS-PL. The initial simulated-transport snapshot passed hosted Windows source/build/model verification. Every newer commit requires its own passing workflow.

An eligibility inquiry was submitted through https://signpath.io/contact on 2026-11-09. The site confirmed submission. Contact details were supplied privately and are omitted from public sources. Foundation eligibility and signing approval remain pending. The formal application and signing-policy documents remain drafts.

Exports exclude binaries, local keys/certificates, machine logs, private correspondence, CAD, firmware, website and purchased reference assets. Vendored originals are checked against pinned Git blob hashes. Read-only CI builds unsigned desktop files twice and runs self/reliability/USB tests without installing a driver or opening hardware ports.

No public signed installer is available. Host Application Control blocks the latest local main executable; guest/clean-Windows driver acceptance is pending. Source publication and CI success do not establish driver eligibility or simulator compatibility.
