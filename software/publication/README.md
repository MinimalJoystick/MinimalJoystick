# MinimalJoystick publication status

The owner approved publication of this software-only prototype under MIT for original software and MS-PL for the Microsoft-derived driver. The public repository is https://github.com/MinimalJoystick/MinimalJoystick, owned by the MinimalJoystick organization.

This initial source snapshot contains the reviewed simulated-transport prototype. Newer USB bridge work in the development workspace is outside this snapshot. No public signed installer or driver release is available. The first hosted source-verification workflow is pending.

An eligibility inquiry was submitted through https://signpath.io/contact on 2026-11-09; the site confirmed submission. It asked about modified Microsoft-sample lineage and UMDF DLL/catalog coverage. Contact details were supplied privately and are omitted here. Foundation acceptance is pending. SIGNPATH-APPLICATION-DRAFT.md remains an unsent formal application draft, separate from that inquiry.

The export excludes binaries, private keys/certificates, machine logs, CAD, firmware, website and purchased reference assets. See AUDIT.md, BUILD.md and THIRD-PARTY-NOTICES.md for evidence and limitations. Source publication does not establish driver-signing eligibility, clean-Windows acceptance or simulator compatibility.
